# Tech Debt Tracker

> 알려진 기술 부채를 추적합니다.
> **에이전트가 반복 실패하는 패턴도 여기에 기록합니다.**
> 해결되면 아래 표의 상태를 업데이트하고, 세부 내용은 `completed/`로 이동하세요.

---

## 형식

```
### [TD-NNN] 제목
- **영역**: 파일/모듈 경로
- **심각도**: High / Medium / Low
- **설명**: 무엇이 문제인가
- **해결 방향**: 어떻게 고칠 것인가
- **등록일**: YYYY-MM-DD
```
