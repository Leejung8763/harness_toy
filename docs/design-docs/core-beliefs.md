# Core Beliefs

> 기술적 결정이 이 믿음에 반한다면 재고해야 합니다.
> 출처: [harness_guide_openai.md](../../harness_guide_openai.md)

---

## 1. 지도를 줘라, 매뉴얼이 아니라

AGENTS.md는 목차입니다. 모든 지침을 한 파일에 몰아넣지 않습니다.
주제별로 파일을 나누고, AGENTS.md는 링크만 유지합니다.

## 2. 경계를 강제하라, 구현을 강제하지 마라

불변 규칙(invariant)은 기계적으로 강제합니다. 구현 방식은 AI에게 맡깁니다.
데이터가 시스템으로 들어오는 경계에서 반드시 유효성을 검증합니다.

## 3. 암묵적 지식은 존재하지 않는다

Google Docs, Slack, 개발자 머릿속의 지식은 에이전트에게 존재하지 않습니다.
모든 비즈니스 로직, 의사결정 배경, 도메인 지식은 코드베이스 안에 있어야 합니다.

## 4. 기술 부채는 고금리 대출이다

복잡하고 일관성 없는 코드는 AI의 추론 비용(토큰, 오류율)을 급격히 올립니다.
AI-Native 리팩토링 = 더 적은 컨텍스트로 정확한 작업이 가능한 환경을 만드는 것.

## 5. 에이전트 실패를 신호로 삼아라 (Mitchell Hashimoto 패턴)

에이전트가 같은 곳에서 반복 실패하면 → 규칙을 AGENTS.md에 추가합니다.
하네스는 한 번에 완성되지 않습니다. 실패를 통해 점진적으로 보강합니다.
